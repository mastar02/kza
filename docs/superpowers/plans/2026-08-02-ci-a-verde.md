> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que el CI ejecute tests por primera vez en la historia del repo, y que los checks que puedan estar en verde lo estén de verdad.

**Architecture:** El CI nunca estuvo verde en 104 corridas desde el 2026-03-09, y `Safety Tests (CRITICAL)` + `Unit Tests` fueron `skipped` 39 de 39 veces. La causa no es el lint: es que esos jobs declaran `needs: lint`, y `lint` es **matemáticamente insatisfacible** porque corre `black --check` e `isort --check-only` sin config y las dos herramientas se contradicen (isort deja 168 archivos que black quiere reformatear; black deja 33 que isort rechaza). El plan desacopla el DAG primero, después pone en verde lo que se puede, y deja el reformateo global como decisión aparte.

**Tech Stack:** GitHub Actions, pytest, ruff 0.15.1, bandit 1.9.4, Python 3.13.
